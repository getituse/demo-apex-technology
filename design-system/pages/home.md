# Home — overrides

Only what differs from [MASTER](../MASTER.md).

**Job of this page:** establish credibility in the first screenful, then give each audience a
single obvious next step. It is the only page allowed to be long.

## Layout rhythm

Alternating `sectionTint` bands, but **never more than two tinted sections in a row** — the page
should feel sectioned, not striped. Density `regular` throughout, stepping to `spacious` for the
about intro and the final CTA so the page opens and closes with air.

Follows the skill's **Trust & Authority + Conversion** pattern:
hero (credibility) → proof → offer overview → clear CTA path — mapped onto the brief's 20-step
structure.

## Hero

Three variants, tenant-selected. All three share: headline readable at 0ms, one primary CTA, one
secondary, no autoplay, no baked-in text.

| Variant     | Use                       | Notes                                                                            |
| ----------- | ------------------------- | -------------------------------------------------------------------------------- |
| `split`     | Default. School / academy | Content left, single strong image right. Stacks image-below on mobile            |
| `editorial` | University / prestige     | Full-width image, scrim, text over. Needs the strongest contrast discipline      |
| `collage`   | Campus life, activity-led | 2–3 layered images, max 12px offset. **Collapses to a single image below 768px** |

Headline ≤10 words. Sub ≤25. An optional admissions badge sits above the headline, never over the
image. Supporting stats appear **below** the CTAs, never inside the image.

## Section-specific notes

**Quick links** — 4–6 items, icon + label, one row desktop / two columns mobile. This is the
highest-traffic element for returning visitors; keep it above the fold on mobile if the tenant
enables it.

**Trust strip** — logos or accreditations only when the tenant has _real_ ones. Otherwise the
section is disabled. Never a row of grey placeholder boxes.

**Stats** — 3–4 maximum. Number in `display` size, label in `small`. Any `isDemoContent` value
carries a visible "sample data" marker. No count-up animation as the primary proof.

**Notice board** — dense and utilitarian by design. Date-led, 5–8 items, scannable. This is the
one section allowed to look like a list rather than a designed block.

**Leadership message** — portrait left at `4/5`, quote right. Signature and role beneath. Keep the
quote under 60 words; link to the full message.

**Final CTA** — inverted band using `primary` as background. Single action. No form here; the form
lives on the conversion page.

## Conversion path

Primary CTA repeats exactly three times: hero, after the programme grid, and the final band.
The header CTA is persistent and is the fourth. Never more.
